Core Competency Assessment

Framework section 8. Core Competency Assessment (CSE-2440, semester 4)

A one-credit, pass/fail practical examination held on lab machines at Level 0. It checks that the student can, unaided: write and debug a small program from a specification; choose and use an appropriate data structure; write SQL queries against a given schema; work in a Linux shell with Git; and read and explain unfamiliar code. It is offered twice each semester: sitting 1 in week 10 of semester 4, once Database Systems has covered the SQL the assessment needs, and sitting 2 in week 14, with remedial clinics in weeks 11–13. Stations already passed are kept. A pass is required before registering for the semester-7 track courses (Track Courses II and III) and Capstone Project I.

The full specification of the assessment, with its stations, marking, sittings and accommodations, is on its course page: CSE-2440 Core Competency Assessment.

Design principles

From framework section 3.

  1. Fewer courses, taught to competence. Excluding GED and MDP, the 2022 syllabus has 73 course units; this draft has 56 for any one student. The freed time goes to practice.
    Shown in: What happened to the 2022 courses
  2. Fundamentals are kept; rote production is cut. Data structures, algorithms, operating systems, databases, networks, architecture and discrete mathematics stay as full courses. What is cut is repeated syntax teaching, legacy hardware detail, and science courses with no downstream use in the programme.
    Shown in: CSE-1123, CSE-2321, CSE-2421, CSE-2425, CSE-2423, CSE-3541, CSE-3543
  3. Do it by hand once, then with tools. Each basic skill is first done unaided (to build the mental model) and afterwards with libraries, frameworks and AI assistants (to reach realistic scale). Repetition for speed is no longer a goal.
    Shown in: AI-use levels, CSE-1121, CSE-2321, CSE-4781, CSE-4783
  4. Every student can explain their own work. AI makes take-home work unreliable as evidence, so each lab has supervised practical tests and a viva, and each studio an individual viva.
    Shown in: Assessment schemes, CSE-2434, CSE-3660
  5. A checked floor for the middle 60%. Each course lists minimum competencies that every passing student must demonstrate, and a programme-level practical assessment in semester 4 gates entry to the final-year work.
    Shown in: Core Competency Assessment, CSE-2440
  6. Tracks with different entry barriers. Five tracks lead to different job families, including ones where mid-level students do well (infrastructure, security operations, testing).
    Shown in: Tracks
  7. Global-market readiness. English technical writing, public evidence of work (repositories), remote-team practices and optional certification alignment are built into courses rather than added as extra courses.
    Shown in: CSE-1130, CSE-4760, CSE-4810, CSE-3543, CSE-3651, CSE-3653, CSE-4781, CSE-3675, CSE-3677, CSE-4777, CSE-4787, CSE-4887

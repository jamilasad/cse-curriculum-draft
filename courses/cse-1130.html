Rationale and what changed

The 2022 syllabus taught technical writing once, in semester 7, and left the command line, version control and debugging tools for students to pick up by themselves; most of the middle of the intake never did. This lab puts both in the first semester, so that every later lab can assume a student who can use a shell, keep work in Git and write a README in English. The writing is kept to the scale a first-semester student can manage: a paragraph, a list of steps, a bug report, an email, a three-minute demonstration. It also gives an honest first account of AI assistants and of why Programming I forbids them. Left out: shell scripting beyond a few lines, Git branching workflows and code review (CSE-2326), formal reports and presentations (CSE-4760).

Minimum competency

Every passing student can, unaided and without AI or translation tools:

  • In a terminal and without a file manager: build a directory tree, copy, move, rename and delete files, find a file by name and a line by its content, send output to a file, and stop a runaway process.
  • Create a repository, make at least three commits with meaningful messages, push to a hosted repository, clone it on a second machine, and bring back an earlier version of a file.
  • Set a breakpoint, step through a short Python program and report the value of a named variable at a given line.
  • Write a README for a small program (what it does, how to run it, one example) that a classmate can follow without asking a question.
  • Write a bug report with a title, steps to reproduce, expected result and actual result.

Stretch goals

  • Write a shell script that automates a repeated task, such as backing up the lab folder under a dated name.
  • Correct something in a classmate's repository through a branch and a pull request, ahead of CSE-2326.
  • Keep personal configuration (aliases, editor settings) in a repository and set it up on a new machine in ten minutes.

Weekly plan

Each session has 15 minutes of touch-typing drill, about 100 minutes of tool work and about 50 minutes on a short writing or speaking task. Target for typing: 25 words per minute at 95% accuracy without looking at the keys by week 14.

Resources

  • Books and notes: William Shotts, The Linux Command Line; Scott Chacon and Ben Straub, Pro Git; the lecture notes of MIT's The Missing Semester of Your CS Education; Mike Markel, Technical Communication (teacher's reference).
  • Software: Ubuntu Linux on lab machines (WSL on students' own Windows laptops), Bash, Git, VS Code, GitHub or a department-hosted GitLab or Gitea server, Klavaro or GNU Typist for typing practice.
  • Templates for the README, bug report and email; the shared glossary; the shared writing rubric.

Notes for the instructor

In the planned public view this section is shown to the committee only (specification 3.4).

  • Do not teach commands as a list to memorise. Every session is a task (find the file, repair the repository), and the commands are what the task needs. Many students arrive with no picture of files and folders; week 1 is for that and should not be rushed.
  • For weak English, give sentence frames and filled examples, set one short piece every week, and mark clarity and completeness before grammar. A dictionary and a spelling checker are allowed; translation tools and AI rewriting are not, and the writing is done in the lab so that it is the student's own.
  • Week 12 must be honest. Show the assistant succeeding as well as failing, and say that the rule is about the stage of learning, not about the tool being bad: a student who cannot trace code cannot check what an assistant writes.
  • Agree the repository layout, the glossary and the week-8 switch to Git with the CSE-1122 instructors before the semester starts.

About this group of courses: Programming and Algorithms

These seven packages form the programming spine of semesters 1 to 4. Programming I (Python) builds the habits of tracing, decomposing, testing and debugging, and the Developer Tools & Technical Communication Lab supplies the shell, Git, editor and writing skills that every later lab assumes. Programming II (C) adds the memory model; Data Structures (C++) and Object-Oriented Programming & Design (Java) build on it in semester 3, and Algorithms in semester 4 turns structures into design techniques. The Core Competency Assessment then checks, unaided, the floor these courses are meant to produce, before students move on to the track courses and the capstone. while permitted AI use rises from Level 0 in semester 1 to Level 2 in later projects and stays at Level 0 in every test, viva and examination.

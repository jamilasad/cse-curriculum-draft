Rationale and what changed

This is the one AI course every student takes, so it is pitched at the mid-level student and assumes only the mathematics of MATH-1209 and STAT-2313. Students have also met gradients, backpropagation by hand and gradient methods in MATH-2409 (semester 4), which the course uses but does not require. It replaces four 2022 courses and their labs (Artificial Intelligence; Machine Learning and Data Mining; Neural Network and Fuzzy System; Pattern Recognition and Image Processing); depth moves to the AI & Data track and application building to CSE-3660. Classical search and reasoning are cut to three weeks. The centre of the course is evaluation: most graduates will use models trained by others, and the skill that lasts is knowing whether a model is good enough and where it fails. Left out: fuzzy systems, expert-system shells, logic programming, genetic algorithms, image-processing filters, and derivations beyond gradient descent for a single neuron. By hand first: search, gradient descent, k-nearest neighbours and one backpropagation step are worked on paper and in NumPy. With tools afterwards: scikit-learn, PyTorch and pretrained models.

Minimum competency

  • Load a CSV file with pandas, clean it, split it into training, validation and test sets, train a scikit-learn classifier, and report a confusion matrix, precision, recall and F1, unaided.
  • Given training and validation scores or curves, say whether a model overfits or underfits and name one remedy.
  • Trace breadth-first search or A* by hand on a small graph and give the order in which nodes are expanded.
  • Carry out by hand one forward pass and one gradient-descent update for a single neuron on two data points.
  • Explain in plain words what a token, an embedding and a context window are, and give one reason a language model can state something false.

Stretch goals

  • Implement a two-layer network with backpropagation in NumPy and check the gradients numerically.
  • Fine-tune a small pretrained transformer for Bangla text classification and compare it with a TF-IDF baseline under the same evaluation.
  • Enter a public competition and write up the validation strategy and what the leaderboard did and did not show.

Assessment

Theory (100). Written mid-term and final (80). At least half the marks are application and analysis: trace A* on a given graph and give the order of expansion; carry out one gradient-descent step with numbers; compute precision, recall and F1 from a confusion matrix and say which matters in the case described (disease screening against spam filtering); find the leakage in a printed pipeline; diagnose a model from its learning curves and name a remedy; run one k-means iteration by hand; choose a model for a scenario and justify the choice; explain why a language model's answer in a printed transcript is wrong and what would reduce the error; analyse a case, such as a loan-approval model trained on past decisions, for bias and privacy risk. Recall is at most a fifth. Continuous assessment (20): Level 0 quizzes (10); two assignments (10), a by-hand problem set (search, gradient descent, metrics) and a written critique of the evaluation in a supplied model report.

Lab (100). Weekly lab work and lab record 30; two supervised practical tests at Level 0 in weeks 6 and 12, 30; lab project 25; individual viva 15. The project, done in pairs, is one supervised-learning task carried from start to finish on a public tabular or text dataset (from the UCI Machine Learning Repository or Kaggle, with local relevance where possible): problem statement, cleaning, a baseline, two models, cross-validated evaluation, error analysis, and a one-page model card stating limits and risks. A student who cannot explain their own project in the viva does not pass the lab.

Resources

  • Textbooks: Russell and Norvig, Artificial Intelligence: A Modern Approach; Géron, Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow; James, Witten, Hastie, Tibshirani and Taylor, An Introduction to Statistical Learning with Applications in Python; Müller and Guido, Introduction to Machine Learning with Python.
  • Software, all free: Python with NumPy, pandas, Matplotlib, scikit-learn and PyTorch; Jupyter; Google Colab or Kaggle notebooks when the lab machines have no GPU.
  • Hardware: ordinary lab computers. Nothing assessed needs a GPU.

Notes for the instructor

In the planned public view this section is shown to the committee only (specification 3.4).

  • Common failure: a reported accuracy near 100% that comes from leakage or from an imbalanced dataset. Weeks 7–8 are the heart of the course; practical test 2 and the project are marked mainly on evaluation.
  • Weaker students: mathematics is the main fear, so introduce every formula with two or three data points worked on the board and examine no derivation beyond the gradient for a single neuron. Use fill-in notebooks in weeks 1–5 with less scaffolding each week, reuse one dataset across weeks 4–9 so that attention goes to method, and allow a printed API reference sheet in practical tests so that they test understanding and not memory of function names.
  • AI: an assistant writes a scikit-learn pipeline in seconds, so marks go to evaluation design, error analysis and explanation. Weekly labs are at Level 1 because their purpose, above all in the from-scratch exercises, is the mental model; assistants may write code only in the project (Level 2, disclosed).
  • Weeks 12–13 date quickly. Revise the examples every year and keep the examined content at concept level.

About this group of courses: Software, Data, AI and Security Core

These six packages run from semester 4 to semester 6 and carry the part of the core in which students build, secure, deploy and extend real software. Database Systems and the Software Engineering package share semester 4: the database course teaches SQL early enough for the studio to use it, and the web application built in the studio becomes an object that later courses return to. Artificial Intelligence & Machine Learning (semester 5) gives the foundations and the habit of honest evaluation that the AI Application & Agent Engineering Studio (semester 6) turns into a shipped product. In semester 6, Information Security attacks and hardens the semester-4 application and Distributed Systems & Cloud Computing containerises, deploys and monitors it, so each student meets the same piece of software as its builder, its attacker and its operator.

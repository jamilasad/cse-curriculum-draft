Rationale and what changed

Linear algebra is the working mathematics of machine learning and data analysis, and numerical computing explains what happens when real-number mathematics is run in floating point. With MATH-1107 this course replaces Mathematics I–IV and Mathematical Analysis for CS, and it absorbs the 2022 Numerical Methods course and its lab. There is no separate lab: four computational assignments in Python with NumPy carry the practical side. Each method is done by hand once on a small case, then written as a short Python function, then replaced by the library call. Left out: abstract vector spaces, cofactor expansion of large determinants, Jordan form, interpolation by difference tables, and long hand iterations of numerical methods.

Minimum competency

Every passing student can, unaided:

  • Solve a 3×3 linear system by elimination by hand, say whether it has no, one or infinitely many solutions, and write the NumPy lines that solve it.
  • Multiply two matrices and compute the dot product, length and angle of two vectors, by hand and in NumPy.
  • Fit a straight line to five data points by least squares using the normal equations.
  • Find the eigenvalues and eigenvectors of a 2×2 matrix.
  • Explain why two floating-point results should not be compared with ==, and carry out three steps of bisection or Newton's method by hand.

Stretch goals

  • Write LU factorisation with partial pivoting and QR by Gram–Schmidt from scratch, and compare them with NumPy on an ill-conditioned matrix.
  • Carry out principal component analysis on a real dataset through the singular value decomposition and interpret the first two components.
  • Show, for a quadratic function, how the largest step size for which gradient descent converges depends on the eigenvalues.

Weekly plan — lab

None. This is a theory-only course with no paired lab. The four NumPy assignments described under Assessment take its place and are done outside class.

Assessment

Theory: mid-term and final (80). The mid-term covers weeks 1–7. At least half the marks are for application and analysis; recall is at most a fifth. Typical questions:

  • Hand computation on small matrices: elimination, LU, a projection, eigenvalues of a 2×2 matrix.
  • NumPy output is given (a rank, singular values, a residual): say what it tells you about the data or the system.
  • A ten-line NumPy function with a defect is given, such as elimination without pivoting or a wrong stopping test: find and fix the defect.
  • Two formulas that are equal in exact arithmetic are given: say which loses accuracy in floating point, and why.
  • Choose a root-finding method for a given function and starting information, and justify the choice.
  • Trace two iterations of gradient descent with a given step size and say whether it is converging.

Continuous assessment (20). Four 15-minute quizzes, best three counted (10), Level 0. Four computational assignments in Python with NumPy and Matplotlib (2.5 each), Level 1, handed in as Jupyter notebooks:

  1. Weeks 2–4: write Gaussian elimination with partial pivoting; compare its answers and running time with numpy.linalg.solve as n grows.
  2. Weeks 5–8: demonstrate cancellation and an ill-conditioned system; fit a line and a polynomial to a supplied set of measurements and plot the residuals.
  3. Weeks 9–11: rank the pages of a small link graph by power iteration; compress a greyscale image with a truncated singular value decomposition.
  4. Weeks 12–14: implement bisection, Newton's method and the trapezoidal rule; run gradient descent on a least-squares problem and plot error against iteration for three step sizes.

Marks go to the comparison and the written explanation in the notebook. The quiz after each assignment includes one question on it, such as predicting the output after one line is changed.

Resources

  • Gilbert Strang, Introduction to Linear Algebra (main text).
  • Stephen Boyd and Lieven Vandenberghe, Introduction to Applied Linear Algebra: Vectors, Matrices, and Least Squares (free; applications).
  • Steven C. Chapra and Raymond P. Canale, Numerical Methods for Engineers (numerical weeks).
  • Python 3 with NumPy, Matplotlib and Jupyter Notebook; SciPy optional.

Notes for the instructor

In the planned public view this section is shown to the committee only (specification 3.4).

  • With no scheduled lab, use the projector for a 15-minute live NumPy demonstration in most weeks, and check in week 1 that every student has a working Python and NumPy installation. If the Mathematics teacher is not a regular Python user, a CSE lab instructor should prepare the starter notebooks and help mark them.
  • Two habits from the old courses should be dropped: elimination taught as a ritual with no picture of what a solution is, and numerical methods taught as long hand-filled iteration tables. Three hand iterations are enough; after that the method is code.
  • For weaker students, issue each assignment as a starter notebook with the plotting code and two test cases already written, so that their effort goes into the algorithm.
  • An AI assistant will write any of these functions on request. At Level 1 students may ask it to explain an error message or a concept, and must say in the notebook what help they used; the follow-up quiz question on their own code is the check.

About this group of courses: Mathematics, Physics and Electrical Fundamentals

This file holds the outlines for the seven mathematics, physics and electrical courses of the programme. The seventh, MATH-2409 Calculus II in semester 4, was added after review of the first draft. Together they replace about 40 credits of mathematics, physics, chemistry and electrical courses in the 2022 syllabus with 23 credits. A topic is kept only if a later course in the programme uses it, and each outline has a table naming the courses that do. The courses are taught as service courses by the Mathematics, Physics and EEE departments, so the outlines are written for a teacher from outside CSE, with examples, assignments and examination questions drawn from computing.
